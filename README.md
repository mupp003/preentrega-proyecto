Proyecto Tienda the legend of zelda
Descripcion: Es un intento de simular una tienda ecommerce
los productos son objetos y referencias, queria alejarme del concepto de ecommerce comun y corriente algo un poco mas vivo y magico tal ves pero no del todo
Esa web simula ser real como si fueras a un bazar se utilizan rupias en lugar de dinero real trata de meterte en la atmosfera

Este proyecto es una pagina web basica desarrollada como parte de un curso de Front -End. la pagina esta estructurada con HTML semantico utiliza las etiquetas <header>,<main>, y <footer> para organizar el contenido. el objetivo es aprender a crear la estructura basica de una pagina web y prepararla para futuras mejoras con CSS y JavaScript.
